# Care Transition Efficiency & Placement Outcome Analytics

## 📌 Project Overview

This project analyzes the efficiency and outcomes of the Unaccompanied Children (UAC) care transition pipeline.

The analysis focuses on the movement of children through:

**CBP Custody → HHS Care → Discharge / Sponsor Placement**

The project uses data analytics and an interactive Streamlit dashboard to identify transition efficiency, discharge performance, bottlenecks, trends, and unusual changes in the care pipeline.

---

## 🎯 Objectives

- Measure CBP → HHS transfer efficiency
- Evaluate HHS discharge effectiveness
- Analyze overall pipeline throughput
- Identify potential bottlenecks and backlog periods
- Analyze temporal trends
- Detect unusual changes and outliers
- Provide data-driven insights and recommendations

---

## 📊 Dataset

The dataset contains daily information about:

- Date
- Children apprehended and placed in CBP custody
- Children in CBP custody
- Children transferred out of CBP custody
- Children in HHS Care
- Children discharged from HHS Care

The dataset was cleaned and transformed before analysis.

---

## 📈 Key Performance Indicators

The project analyzes the following metrics:

- Transfer Efficiency Ratio
- Discharge Effectiveness
- Pipeline Throughput
- Backlog
- Outcome Stability
